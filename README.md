# 💈 Sistema de Gerenciamento para Barbearias

Sistema web desenvolvido para automatizar o gerenciamento de barbearias, oferecendo controle de clientes, barbeiros, serviços, agendamentos e administração completa do negócio.

<div align="center">

## 📌 Visão Geral

</div>

> Sistema web desenvolvido para facilitar o gerenciamento de barbearias, centralizando processos como cadastro de clientes, gerenciamento de barbeiros, controle de serviços, agendamentos e administração do negócio em uma única plataforma.

---

<div align="center">

## 🎯 Objetivo

</div>

> Desenvolver uma aplicação web moderna, intuitiva e responsiva capaz de otimizar a rotina de uma barbearia, reduzindo processos manuais e proporcionando maior organização dos atendimentos.

## ⚙️ Funcionalidades

</div>

### 👤 Gestão de Clientes

- Cadastro de clientes
- Atualização de informações
- Exclusão de clientes
- Consulta de histórico de atendimentos

### 💈 Gestão de Barbeiros

- Cadastro de barbeiros
- Atualização de dados
- Gerenciamento de disponibilidade
- Cadastro de especialidades

### ✂️ Gestão de Serviços

- Cadastro de serviços
- Definição de preços
- Tempo estimado do atendimento
- Ativação e desativação de serviços

### 📅 Agendamentos

- Agendamento online
- Seleção de barbeiro
- Seleção de serviço
- Escolha de data e horário
- Alteração do status do atendimento
- Cancelamento de agendamentos

### 📊 Dashboard Administrativo *(Em desenvolvimento)*

- Quantidade de atendimentos
- Agendamentos do dia
- Clientes cadastrados
- Faturamento
- Relatórios

### 🔒 Autenticação *(Planejado)*

- Login
- Controle de acesso
- Diferentes níveis de permissão
- Administrador
- Barbeiro
- Cliente
